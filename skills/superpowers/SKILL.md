# Superpowers Entry Point (`/superpowers`)

When `/superpowers` is invoked, immediately read and follow `../using-superpowers/SKILL.md` to select and enforce the appropriate Superpowers workflow for the user's task:

- **New feature / design:** `../brainstorming/SKILL.md` (`/brainstorming`)
- **Multi-step plan:** `../writing-plans/SKILL.md` (`/writing-plans`)
- **Execute plan:** `../executing-plans/SKILL.md` (`/executing-plans`) or `../subagent-driven-development/SKILL.md` (`/subagent-driven-development`)
- **Implementation:** `../test-driven-development/SKILL.md` (`/test-driven-development`)
- **Bug / failure:** `../systematic-debugging/SKILL.md` (`/systematic-debugging`)
- **Completion check:** `../verification-before-completion/SKILL.md` (`/verification-before-completion`)
- **Code review / branch finish:** `../requesting-code-review/SKILL.md`, `../receiving-code-review/SKILL.md`, `../finishing-a-development-branch/SKILL.md`
